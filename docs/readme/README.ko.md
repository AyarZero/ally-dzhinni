# AllY · 지니 (v0.1)

공유 대화 기록, 로컬 디스크 메모리, 작업 대기열, 한도 관리를 하나의 창에 통합하여 여러 AI 모델을 함께 사용할 수 있는 Windows용 로컬 데스크톱 셸입니다.

*AllY · 지니의 탄생일은 2026년 11월 23일입니다. 라이선스: MIT.*

---

## 어떤 앱이며 어떤 문제를 해결하나요

AI를 꾸준히 사용하다 보면 작업이 여러 브라우저 탭, 콘솔 창, 개별 키로 금방 흩어집니다. 한 모델의 5시간 한도가 소진되면 다른 모델을 열고 프로젝트 컨텍스트를 처음부터 다시 설명해야 합니다.

**AllY · 지니**는 네 가지 실무적인 과제를 해결합니다:

- **모델 간 통합 컨텍스트.** 대화 기록과 규칙 베이스는 로컬 Markdown 파일(`pamyat/`)에 저장됩니다. 입력창에서 바로 AI 엔진, 모델 또는 추론 깊이를 전환하여 다음 모델이 같은 지점에서 작업을 이어갈 수 있습니다.
- **투명한 CLI 에이전트 작업.** 일반 터미널에서는 에이전트의 현재 단계를 제때 파악하고 작업 도중 개입하기 어렵습니다. AllY에서는 너비를 조절할 수 있는 부드러운 세로 구분선 왼쪽에 상태 구체와 실시간 작업 피드가 표시되고, 오른쪽에는 실시간 보완(`live-steer`), 대기열 편집, 중요 메시지 우선 처리를 지원하는 대화창과 작업 대기열이 배치됩니다.
- **한도 및 컨텍스트 창 제어.** **「리소스」** 위젯은 주도 AI 모델, 컨텍스트 사용량(임계값 `350k`), 구독의 5시간 및 주간 할당량을 표시하며, **「보조」** 탭은 나머지 연결들의 잔액을 모아 보여줍니다. 지표는 유료 백그라운드 호출 없이 로컬에서 읽어옵니다.
- **데이터 통제 및 직접 연결.** 대화 내역, `pamyat/` 메모, `.claude/skills/` 스킬, `.ally-data/` 로컬 설정은 사용자의 PC에 그대로 유지됩니다. 선택한 프로바이더에 본인의 구독과 키를 직접 연결해 사용합니다.

## 누구를 위한 앱인가요

- Claude Code, Codex, Antigravity 또는 DeepSeek으로 프로젝트를 진행하며 에이전트 단계, 대기열, 컨텍스트 소모량을 하나의 제어 가능한 창에서 확인하고 싶은 **개발자와 바이브 코더**.
- 자신의 PC에 프로젝트별 통합 로컬 메모리가 필요한 **작가, 창업가, 전문가**.
- 작업에 맞게 레이아웃을 커스터마이징하고 내장 피드백을 통해 다음 릴리스에 의견을 반영할 수 있는 로컬 도구가 필요한 **Windows 10/11 사용자**.

## 버전 0.1에서 실제로 동작하는 기능

### 1. 연결 및 「자동」 모드
시작하려면 최소 한 가지 옵션만 연결하면 됩니다. **「자동」** 모드에서는 시스템이 사용 가능한 실행기를 자동으로 선택합니다:

| 연결 | 동작 방식 | v0.1 지원 기능 |
|---|---|---|
| **Claude Code** | Anthropic Pro / Max 구독 기반 공식 CLI | 복잡한 작업, 코드, 텍스트, 플래닝, 컨텍스트 자동 압축 |
| **Codex** | ChatGPT Plus / Pro 구독 기반 공식 CLI | 저장소 단위 작업 및 응답 도중 실시간 보완(`live-steer`) |
| **Antigravity** | Google AI 공식 CLI | 대용량 컨텍스트 분석(컨텍스트 창 임계값 `350k`) 및 할당량 추적 |
| **DeepSeek Harness** | DeepSeek 잔액 기반 로컬 headless 프로필 `dsh` | 예비 및 경제적 실행기, 「보조」 탭에서 잔액 확인 |
| **API 애그리게이터 (OpenRouter)** | Base URL과 키 기반의 모든 Anthropic 호환 게이트웨이 | 로컬 Claude Code CLI 프로세스를 통한 외부 모델 연결 (Anthropic 구독 불필요) |
| **Qoder CLI** | 로컬 CLI (감지 및 로그인) | 연결 마법사에서 감지(창 내부 로그인 포함); 채팅 주도 역할은 다음 업데이트에 제공 예정 |

### 2. 작업 공간 및 인터페이스
- **시작 화면:** 왼쪽에는 텍스트 없는 깨끗한 상태 구체와 실시간 단계 흐름, 부드러운 세로 구분선이 있는 **「대화」**가 배치되고, 오른쪽 위에는 **「리소스」 / 「보조」**, 아래에는 **「노트북」** 모니터가 있으며 높이를 자유롭게 조절할 수 있습니다.
- **상단 바(오른쪽에서 왼쪽 순):** 오른쪽 시계, 넓은 **피드백 패널(벌레 아이콘)**, **브러시**(위젯 이동·크기 조절·초기화), **테마**(기본값 **그래파이트**, 청록·미드나이트·다크·라이트 포함), 창 안의 **책 아이콘(가이드 및 버전 기록)**, **번개 아이콘**(전체 폭 **「읽기 모드」**가 포함된 3단계 연결 마법사).
- **로컬 저장소:** `pamyat/`(로컬 Markdown 메모리), `.claude/skills/`(로컬 스킬), `.ally-data/`(키 및 창 레이아웃, Git에서 제외됨).

## 설치 및 실행 (Windows 10/11)

**설치 전에 시스템에 다음 항목이 이미 설치되어 있고 `PATH`에 등록되어 있는지 확인하세요:**
1. **Node.js 24+** (내장 `node:sqlite` 모듈 지원 포함)
2. **Python 3**
3. **Git**
4. 초기 빌드 중 인터넷 연결(`npm ci` 및 Electron 다운로드용)과 최소 한 개 이상의 연결된 AI 엔진 또는 키.

편한 세 가지 설치 방법 중 하나를 선택하세요:

### 방법 1 — 압축 파일과 익숙한 `.exe` 사용
1. 저장소 ZIP 압축 파일을 다운로드해 `C:\AllY`처럼 영문으로 된 짧은 경로에 압축을 풉니다.
2. **`AllY.exe`**를 더블 클릭합니다. 처음 실행할 때 `node` 24+, `python`, `git` 여부를 확인하고 의존성을 설치하며 Electron을 다운로드한 뒤 실행 파일 **`programma\Dzhinni.exe`**를 빌드하고 바탕 화면에 **`AllY`** 바로 가기를 만든 다음 창을 바로 엽니다.
  *서명되지 않은 새 `.exe`에 대해 Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요(런처 소스는 `docs/launchers/`에 공개되어 있으며 `.\ustanovka.ps1`을 직접 실행할 수도 있습니다).*
3. 이후에는 **`AllY.exe`**, 바탕 화면의 **`AllY`** 바로 가기 또는 **`programma\Dzhinni.exe`**를 더블 클릭해 실행할 수 있습니다. 별도의 앱 창에서 가이드와 버전 기록을 열려면 **`AllY-Guide.exe`**를 실행하세요.
4. 처음 실행하면 3단계 시작 마법사가 열립니다. 원하는 AI 모델을 연결하고 첫 메시지를 보내 보세요.

### 방법 2 — 터미널 명령어 사용 (PowerShell / cmd)
PowerShell을 열고 순서대로 실행하세요:

```powershell
git clone https://github.com/AyarZero/ally-dzhinni.git C:\AllY
cd C:\AllY
.\AllY.exe
```

나중에 빌드 준비 상태를 확인하려면 다음 명령어를 실행하세요:

```powershell
.\AllY.exe -Proverka
```

터미널에서 실행:

```powershell
.\AllY.exe
```

### 방법 3 — 로컬 AI 도우미용 설치 프롬프트
PC에 이미 Claude Code, Codex, Antigravity 또는 다른 AI 도우미가 실행 중이라면 아래 텍스트 전체를 복사해 그대로 전달하세요:

```text
이 Windows PC에 https://github.com/AyarZero/ally-dzhinni 저장소로부터 로컬 데스크톱 앱 AllY · 지니 (v0.1)를 설치하고 실행할 수 있도록 준비해 줘:
1. 터미널에서 `git`, `python`(Python 3), `node`(Node.js 24+ 및 `node -e "require('node:sqlite')"` 정상 동작 확인 필요) 유무를 점검해 줘. 누락된 항목이 있거나 Node 버전이 24 미만이면 빌드 전에 알려주고 설치를 도와줘.
2. `C:\AllY`처럼 공백이나 비영문 문자가 없는 짧은 경로로 저장소를 클론하고 해당 폴더로 이동해 줘.
3. `powershell -NoProfile -ExecutionPolicy Bypass -File .\ustanovka.ps1`로 설치를 실행하고 `programma\Dzhinni.exe` 빌드가 완료될 때까지 기다려 줘.
4. `powershell -NoProfile -ExecutionPolicy Bypass -File .\ustanovka.ps1 -Proverka` 명령어로 빌드를 검증해 줘.
5. 시스템에 어떤 CLI 엔진(Claude Code, Codex, Antigravity, DeepSeek Harness, Qoder)이나 OpenRouter 키가 이미 사용 가능한지 확인하고, 현재 준비된 항목을 간단히 알려줘.
6. `programma\Dzhinni.exe`(또는 `.\AllY.exe`)를 실행하고 AllY 창을 열어 작업을 시작해도 된다고 알려줘.
```

*참고: 연결된 CLI 실행기는 매번 읽기/수정 확인을 묻지 않고 열려 있는 작업 폴더의 파일에 직접 작업합니다. 중요한 프로젝트는 Git으로 관리하세요.*

## 피드백 및 프로젝트 참여

상단 헤더 오른쪽(시계 왼쪽)에는 **벌레 아이콘 버튼 — 「피드백」**이 있습니다. 이 버튼을 통해 인터페이스에서 바로 다음 작업을 수행할 수 있습니다:

- 버그, 인터페이스 깨짐 또는 실행 오류 보고;
- 메시지에 증빙 파일 최대 **3개** 첨부: 텍스트 로그 `.txt` / `.md` (최대 `2 MB`), 스크린샷 `.png` / `.jpg` / `.jpeg` / `.webp` / `.gif` (최대 `10 MB`) 또는 짧은 동영상 `.mp4` / `.webm` / `.mov` (최대 `25 MB`, 총합 최대 `30 MB`);
- 새로운 모듈, 스킬 또는 활용 시나리오 제안.

전송되는 것은 **양식 텍스트와 직접 선택한 파일뿐**이며 대화 기록, 개인 메모, 키는 로컬에 유지됩니다. 개발자의 답변은 앱 내 대화창으로 다시 전달됩니다. 이 프로젝트는 MIT 라이선스로 공개되어 있으므로 `.claude/skills/`에 자신만의 스킬을 만들고 코어 개선에도 참여할 수 있습니다.

## 현재 작업 중인 v0.1의 알려진 문제 및 제한 사항

현재 제한되어 있거나 개선 작업이 진행 중인 사항을 투명하게 공유합니다:

1. **환경 의존성 사전 설치 필요:** `v0.1` 설치에는 이미 설치된 `Node.js 24+`, `Python 3`, `Git`이 필요합니다. 수동 사전 준비가 필요 없는 단일 독립형 `.exe` 설치 프로그램은 아직 개발 중입니다.
2. **v0.1 클라이언트 빌드에서 음성 입력 및 음성 출력 비활성화:** 로컬 음성 인식(`GigaAM`) 및 설치 프로그램 마무리 단계에서 마이크 및 음성 버튼이 일시적으로 숨겨져 있습니다.
3. **일기(「솔직한 대화」)는 v0.1 클라이언트 빌드에서 숨김 처리되어 있습니다:** 다중 엔진 지원이 완성되는 대로 다음 업데이트에서 열릴 예정입니다.
4. **창을 닫은 후 백그라운드 브리지의 점진적 절전 전환:** 창을 닫은 직후 다른 인스턴스를 바로 다시 열 경우, 로컬 브리지 서버가 유휴 타임아웃(최대 약 9분)을 거쳐 종료될 수 있습니다.
5. **Qoder 통합 진행 중:** 연결 마법사가 로컬 Qoder CLI와 로그인 상태를 감지하지만, 대화창에서 Qoder를 주도 역할로 사용하는 기능은 다음 릴리스까지 비활성화되어 있습니다.
6. **피드백 대용량 첨부 파일 서버 수신 업데이트 진행 중:** 백엔드 업데이트 완료 전까지 스크린샷이나 동영상 전송 시 피드백 서버가 크기 또는 파일 거부 오류를 반환할 경우, 작성 중인 초안을 잃지 않고 텍스트만으로 즉시 전송할 수 있습니다.
7. **플랫폼:** **Windows 10/11** 환경에서만 테스트 및 빌드되었습니다.
