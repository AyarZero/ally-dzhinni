# AllY · ג'יני (v0.1)

מעטפת שולחן עבודה מקומית עבור Windows, המאחדת מספר מודלי בינה מלאכותית בחלון אחד עם היסטוריית שיחה משותפת, זיכרון מקומי בדיסק, תור משימות ומעקב מגבלות.

*יום ההולדת של AllY · ג'יני — 23 בנובמבר 2026. רישיון: MIT.*

---

## מהי האפליקציה הזו ואיזו בעיה היא פותרת

בעבודה שוטפת עם בינה מלאכותית, משימות מתפזרות במהירות בין לשוניות דפדפן, חלונות מסוף ומפתחות נפרדים. כשמודל אחד מגיע למגבלת 5 השעות שלו, צריך לפתוח מודל אחר ולהסביר את הקשר הפרויקט מחדש.

**AllY · ג'יני** נותנת מענה לארבעה צרכים מעשיים:

- **הקשר אחיד בין מודלים.** היסטוריית השיחה ובסיס הכללים שלכם נשמרים מקומית בקובצי Markdown (`pamyat/`). אפשר להחליף מנוע, מודל או עומק חשיבה ישירות בשורת הקלט, כדי שהמודל הבא ימשיך את המשימה מאותה נקודה.
- **שקיפות בעבודת סוכני CLI.** במסוף רגיל קשה להבחין בזמן בצעד הנוכחי של הסוכן ולהתערב תוך כדי תנועה. ב-AllY מוצגים בצד שמאל כדור המצב וערוץ הפעולות השוטפות מאחורי מפריד אנכי חלק הניתן לגרירה לשינוי רוחב, ובצד ימין מופיעים השיחה ותור המשימות עם תמיכה בהכוונה בזמן אמת (`live-steer`), עריכת התור וקידום הודעה חשובה.
- **בקרת מגבלות וחלון הקשר.** הווידג'ט **«משאבים»** מציג את המנוע המוביל, ניצול חלון ההקשר (עם סף `350k`), ומכסות מנוי ל-5 שעות ולשבוע, בעוד הלשונית **«עוזרים»** מרכזת את היתרות של שאר החיבורים. המדדים נקראים מקומית ללא קריאות רקע בתשלום.
- **שליטה בנתונים וחיבורים ישירים.** השיחות, ההערות ב-`pamyat/`, המיומנויות ב-`.claude/skills/` וההגדרות המקומיות ב-`.ally-data/` נשארים במחשב שלכם. אתם משתמשים במנויים ובמפתחות שלכם ישירות מול הספקים שבחרתם.

## למי מיועדת האפליקציה

- **מפתחים ו-vibe coders** שמנהלים פרויקטים דרך Claude Code, Codex, Antigravity או DeepSeek ורוצים לראות את שלבי הסוכנים, התור וצריכת ההקשר בחלון נשלט אחד.
- **כותבים, יזמים ואנשי מקצוע** הזקוקים לזיכרון מקומי אחיד עבור הפרויקטים שלהם על המחשב האישי.
- **משתמשי Windows 10/11** המחפשים כלי מקומי עם פריסת ממשק מותאמת למשימות שלהם ואפשרות להשפיע על הגרסאות הבאות דרך מנגנון המשוב המובנה.

## מה עובד בפועל בגרסה 0.1

### 1. חיבורים ומצב «אוטומטי»
כדי להתחיל, מספיק לחבר אפשרות אחת לפחות. במצב **«אוטומטי»** המערכת בוחרת מבצע זמין בעצמה:

| חיבור | אופן הפעולה | יכולות ב-v0.1 |
|---|---|---|
| **Claude Code** | CLI רשמי עם מנוי Anthropic Pro / Max | משימות מורכבות, קוד, כתיבה, תכנון ודחיסה אוטומטית של ההקשר |
| **Codex** | CLI רשמי עם מנוי ChatGPT Plus / Pro | עבודה מול מאגרי קוד והכוונה תוך כדי תשובה (`live-steer`) |
| **Antigravity** | CLI רשמי של Google AI | ניתוחים עם הקשר רחב (סף חלון `350k`) ומעקב מכסות |
| **DeepSeek Harness** | פרופיל headless מקומי `dsh` לפי יתרת DeepSeek | מבצע גיבוי וחסכוני, בדיקת יתרה בלשונית «עוזרים» |
| **מאגד API (OpenRouter)** | כל שער תואם-Anthropic לפי Base URL ומפתח | חיבור מודלים חיצוניים דרך תהליך מקומי של Claude Code CLI (ללא מנוי Anthropic) |
| **Qoder CLI** | CLI מקומי (זיהוי והתחברות) | מזוהה על ידי אשף החיבורים (כולל התחברות מתוך החלון); תפקיד המנוע המוביל בצ'אט יגיע בעדכון הבא |

### 2. סביבת העבודה והממשק
- **מסך פתיחה:** בצד אחד פתוחה **«שיחה»** עם כדור מצב נקי מטקסט וציר שלבים חי, ובצד השני **«משאבים» / «עוזרים»** (למעלה) ו**«מחשב»** (למטה) הניתנים לשינוי גובה חופשי.
- **הסרגל העליון (מימין לשמאל):** שעון בקצה, חלונית **משוב רחבה (חיפושית)**, **מברשת** (הזזה ושינוי גודל ווידג'טים, איפוס פריסה), **ערכות נושא** (**גרפיט** כברירת מחדל, וכן טורקיז, חצות, כהה ובהירה), **סמל ספר** (מדריך והיסטוריית גרסאות בתוך החלון) ו**ברק** (אשף חיבורים בן 3 שלבים עם **«מצב קריאה»** רחב).
- **אחסון מקומי:** `pamyat/` (זיכרון Markdown מקומי), `.claude/skills/` (מיומנויות מקומיות), `.ally-data/` (מפתחות ופריסת החלון, מוחרגת מ-Git).

## התקנה והפעלה (Windows 10/11)

**לפני ההתקנה ודאו שהרכיבים הבאים כבר מותקנים וזמינים ב-`PATH`:**
1. **Node.js 24+** (עם תמיכה במודול המובנה `node:sqlite`)
2. **Python 3**
3. **Git**
4. חיבור לאינטרנט בזמן הבנייה הראשונה (`npm ci` והורדת Electron) ולפחות מנוע בינה מלאכותית או מפתח אחד מחובר.

בחרו אחת משלוש דרכי ההתקנה הנוחות:

### דרך 1 — דרך ארכיון וקובץ `.exe` מוכר
1. הורידו את ארכיון ה-ZIP של המאגר וחלצו אותו לנתיב קצר ללא תווים לא-לטיניים, למשל `C:\AllY`.
2. לחצו לחיצה כפולה על **`AllY.exe`** — בהפעלה הראשונה הקובץ יבדוק `node` 24+, `python` ו-`git`, יתקין תלויות, יוריד את Electron, יבנה את קובץ ההפעלה **`programma\Dzhinni.exe`**, ייצור קיצור דרך **`AllY`** בשולחן העבודה ויפתח את החלון.
  *אם Windows SmartScreen מציג אזהרה לקובץ `.exe` חדש ללא חתימה, לחצו **מידע נוסף ← הפעל בכל זאת** (קוד המקור של המפעילים פתוח ב-`docs/launchers/`, או הפעילו ישירות `.\ustanovka.ps1`).*
3. בהמשך הפעילו את האפליקציה בלחיצה כפולה על **`AllY.exe`**, על קיצור הדרך **`AllY`** בשולחן העבודה או ישירות דרך **`programma\Dzhinni.exe`**. כדי לפתוח את המדריך והיסטוריית הגרסאות בחלון יישום נפרד, הפעילו את **`AllY-Guide.exe`**.
4. בהפעלה הראשונה ייפתח אשף ההתחלה בן 3 השלבים — חברו את המודל הרצוי ושלחו הודעה ראשונה.

### דרך 2 — באמצעות פקודות במסוף (PowerShell / cmd)
פתחו את PowerShell והריצו לפי הסדר:

```powershell
git clone https://github.com/AyarZero/ally-dzhinni.git C:\AllY
cd C:\AllY
.\AllY.exe
```

כדי לבדוק את תקינות הבנייה מאוחר יותר, הריצו:

```powershell
.\AllY.exe -Proverka
```

הפעלה מהמסוף:

```powershell
.\AllY.exe
```

### דרך 3 — פרומפט מוכן לסוכן הבינה המלאכותית המקומי שלכם
אם כבר פועל אצלכם במחשב Claude Code, Codex, Antigravity או עוזר בינה מלאכותית אחר, העתיקו את הטקסט הבא במלואו ושלחו לו:

```text
התקן והכן להפעלה את אפליקציית שולחן העבודה המקומית AllY · ג'יני (v0.1) על מחשב Windows זה מתוך המאגר https://github.com/AyarZero/ally-dzhinni:
1. בדוק במסוף אם מותקנים `git`, `python` (Python 3) ו-`node` (נדרשת גרסת Node.js 24+ עם בדיקה תקינה של `node -e "require('node:sqlite')"`). אם חסר רכיב כלשהו או שגרסת Node נמוכה מ-24 — הודע לי ועזור להשלים את ההתקנה לפני הבנייה.
2. שכפל (clone) את המאגר לנתיב קצר ללא רווחים ותווים מיוחדים, למשל `C:\AllY`, ועבור לתיקייה זו.
3. הרץ את ההתקנה: `powershell -NoProfile -ExecutionPolicy Bypass -File .\ustanovka.ps1` והמתן לסיום הבנייה של `programma\Dzhinni.exe`.
4. אמת את הבנייה באמצעות `powershell -NoProfile -ExecutionPolicy Bypass -File .\ustanovka.ps1 -Proverka`.
5. בדוק אילו מנועי CLI (Claude Code, Codex, Antigravity, DeepSeek Harness, Qoder) או מפתחות OpenRouter כבר זמינים במערכת, וסכם לי בקצרה מה כבר מוכן.
6. הפעל את `programma\Dzhinni.exe` (או `.\AllY.exe`) והודע לי שאפשר לפתוח את החלון של AllY ולהתחיל לעבוד.
```

*הערה: מבצעי CLI מחוברים עובדים ישירות מול קובצי תיקיית העבודה הפתוחה ללא אישור נפרד לכל קריאה או עריכה — שמרו פרויקטים חשובים תחת Git.*

## משוב והשתתפות בפיתוח הפרויקט

בצדה הימני של הכותרת העליונה (משמאל לשעון) נמצא כפתור עם **סמל חיפושית — «משוב»**. דרכו ניתן לבצע ישירות מתוך הממשק:

- לדווח על באג, תקלה בממשק או בעיית הפעלה;
- לצרף להודעה עד **3 קבצי** תיעוד: לוגים טקסטואליים `.txt` / `.md` (עד `2 MB`), צילומי מסך `.png` / `.jpg` / `.jpeg` / `.webp` / `.gif` (עד `10 MB`) או סרטונים קצרים `.mp4` / `.webm` / `.mov` (עד `25 MB`, ובסה"כ עד `30 MB`);
- להציע מודול חדש, מיומנות או תרחיש שימוש.

נשלחים **רק טקסט הטופס והקבצים שבחרתם** — השיחות, ההערות האישיות והמפתחות נשארים מקומיים. תשובות המפתחים חוזרות ישירות לצ'אט באפליקציה. הפרויקט פתוח תחת רישיון MIT: תוכלו ליצור מיומנויות משלכם ב-`.claude/skills/` ולהשתתף בפיתוח הליבה.

## בעיות מוכרות ומגבלות ב-v0.1 שעליהן אנו עובדים כעת

אנו מתעדים בשקיפות את מה שעדיין מוגבל או נמצא בהשלמה כרגע:

1. **תלויות סביבה מותקנות מראש:** התקנת `v0.1` דורשת ש-`Node.js 24+`, `Python 3` ו-`Git` כבר יהיו מותקנים — מתקין `.exe` עצמאי ללא הכנה ידנית עדיין בפיתוח.
2. **קלט קולי והקראה מוסתרים בבניית הלקוח של v0.1:** כפתורי המיקרופון והקול הוסרו זמנית בזמן השלמת זיהוי הדיבור המקומי (`GigaAM`) והמתקין שלו.
3. **היומן («שיחה כנה») מוסתר בגרסת הלקוח v0.1:** התמיכה בכל המנועים עדיין בהשלמה, והלשונית תיפתח בעדכון הקרוב.
4. **כיבוי הדרגתי של גשר הרקע לאחר סגירת החלון:** בעת סגירת החלון, שרת הגשר המקומי עשוי להיסגר לאחר פסק זמן של חוסר פעילות (עד כ-9 דקות) אם פותחים מיד מופע אחר.
5. **Qoder בתהליך שילוב:** אשף החיבורים מזהה את ה-CLI המקומי של Qoder ואת מצב ההתחברות, אך השימוש ב-Qoder כמנוע מוביל בשיחה חסום עד לשחרור הבא.
6. **קליטת קבצים גדולים בשרת המשוב:** אם בעת שליחת צילום מסך או סרטון שרת המשוב מחזיר שגיאת גודל או אי-קבלת קובץ לפני השלמת עדכון השרת, ניתן לשלוח מיד את הטופס כטקסט מבלי לאבד את הטיוטה.
7. **פלטפורמה:** נבדק ונבנה עבור **Windows 10/11** בלבד.
