# AllY · Джинні (v0.1)

Локальна десктопна оболонка для Windows, що об’єднує кілька нейромереж в одному вікні зі спільною історією розмови, локальною пам’яттю на диску, чергою завдань, і контролем лімітів.

*День народження AllY · Джинні — 23 листопада 2026 року. Ліцензія: MIT.*

---

## Що це за застосунок і яку проблему він розв’язує

За регулярної роботи з ШІ завдання швидко розпорошуються між різними вкладками браузера, консольними вікнами й окремими ключами. Коли в однієї моделі вичерпується п’ятигодинний ліміт, доводиться відкривати іншу й заново пояснювати контекст проєкту.

**AllY · Джинні** розв’язує чотири практичні завдання:

- **Єдиний контекст між моделями.** Історія розмови й ваша база правил зберігаються локально в Markdown-файлах (`pamyat/`). Перемкнути нейромережу, модель або глибину міркувань можна прямо в рядку введення, щоб наступна модель продовжила завдання з того самого місця.
- **Прозора робота CLI-агентів.** У звичайному терміналі складно вчасно побачити поточний крок агента й втрутитися під час роботи. В AllY ліворуч показано сферу стану й стрічку поточних дій за плавною вертикальною межею зі змінною шириною, а праворуч — листування й чергу завдань із підтримкою уточнень на ходу (`live-steer`), редагування черги та прискорення важливого повідомлення.
- **Контроль лімітів і контекстного вікна.** Віджет **«Ресурси»** показує провідну нейромережу, заповнення контексту (з порогом `350k`), 5-годинні й тижневі квоти підписок, а вкладка **«Помічники»** збирає баланси решти підключень. Показники зчитуються локально без платних фонових викликів.
- **Контроль даних і прямі підключення.** Листування, нотатки `pamyat/`, навички `.claude/skills/` і локальні налаштування `.ally-data/` залишаються на вашому комп’ютері. Ви використовуєте власні підписки й ключі безпосередньо в обраних провайдерів.

## Що реально працює у версії 0.1

### 1. Підключення й режим «Авто»
Для початку достатньо підключити хоча б один варіант. У режимі **«Авто»** система сама вибирає доступного виконавця:

| Підключення | Спосіб роботи | Що вміє у v0.1 |
|---|---|---|
| **Claude Code** | Офіційний CLI за підпискою Anthropic Pro / Max | Складні завдання, код, тексти, планування й автоматичне стиснення контексту |
| **Codex** | Офіційний CLI за підпискою ChatGPT Plus / Pro | Робота з репозиторіями й уточнення безпосередньо під час відповіді (`live-steer`) |
| **Antigravity** | Офіційний CLI Google AI | Розбір із великим контекстом (поріг вікна `350k`) і відстеженням квот |
| **DeepSeek Harness** | Локальний headless-профіль `dsh` з оплатою з балансу DeepSeek | Резервний і економний виконавець, перевірка балансу на вкладці «Помічники» |
| **Агрегатор API (OpenRouter)** | Будь-який Anthropic-сумісний шлюз за Base URL і ключем | Підключення зовнішніх моделей через локальний процес Claude Code CLI (без підписки Anthropic) |
| **Qoder CLI** | Локальний CLI (виявлення та вхід) | Визначається майстром підключення (включно зі входом із вікна); роль провідного виконавця в чаті з’явиться в наступному оновленні |

### 2. Робочий простір та інтерфейс
- **Початковий екран:** ліворуч розташоване **«Листування»** з чистою сферою стану, стрічкою кроків і плавною вертикальною межею; праворуч — віджети **«Ресурси» / «Помічники»** (згори) і **«Ноутбук»** (знизу), межі яких вільно тягнуться в режимі налаштування.
- **Верхня панель (справа наліво):** годинник праворуч, широка панель **зворотного зв’язку (жучок)** для тексту та вкладень, **пензель** (перетягування й зміна розмірів блоків, вкладок та іконок, скидання), **теми** (типово **Графіт**, також Бірюзова, Північ, Темна й Світла), **книга (довідка та звід версій)** усередині вікна й акцентна **блискавка** (3-кроковий майстер підключень із широким **«Режимом читання»**).
- **Локальне зберігання:** `pamyat/` (локальна Markdown-пам’ять), `.claude/skills/` (локальні навички), `.ally-data/` (ключі й компонування вікна, виключена з Git).

## Встановлення й запуск (Windows 10/11)

**Перед встановленням переконайтеся, що в системі вже встановлені й доступні в `PATH`:**
1. **Node.js 24+** (з підтримкою вбудованого модуля `node:sqlite`)
2. **Python 3**
3. **Git**
4. Доступ до інтернету на час першого збирання (`npm ci` і завантаження Electron) та хоча б один підключений ШІ-рушій або ключ.

Виберіть будь-який із трьох зручних способів встановлення:

### Спосіб 1 — через архів і знайомий `.exe`
1. Завантажте ZIP-архів репозиторію й розпакуйте його в короткий шлях без кирилиці, наприклад `C:\AllY`.
2. Двічі клацніть **`AllY.exe`** — під час першого запуску він перевірить `node` 24+, `python` і `git`, встановить залежності, завантажить Electron, збере виконуваний файл **`programma\Dzhinni.exe`**, створить ярлик **`AllY`** на робочому столі й одразу відкриє вікно.
  *Якщо Windows SmartScreen покаже попередження для нового непідписаного `.exe`, натисніть «Докладніше» → «Виконати в будь-якому разі» (вихідний код лаунчерів відкритий у `docs/launchers/`, або запустіть `.\ustanovka.ps1` напряму).*
3. Надалі запускайте застосунок подвійним клацанням **`AllY.exe`**, ярлика **`AllY`** на робочому столі або безпосередньо через **`programma\Dzhinni.exe`**. Документацію та звід версій в окремому вікні застосунку відкриває **`AllY-Guide.exe`**.
4. Під час першого запуску відкриється 3-кроковий майстер початкового налаштування — підключіть потрібну нейромережу й надішліть перше повідомлення.

### Спосіб 2 — командами в терміналі (PowerShell / cmd)
Відкрийте PowerShell і виконайте по черзі:

```powershell
git clone https://github.com/AyarZero/ally-dzhinni.git C:\AllY
cd C:\AllY
.\AllY.exe
```

Перевірити готовність збірки пізніше можна командою:

```powershell
.\AllY.exe -Proverka
```

Запуск із термінала:

```powershell
.\AllY.exe
```

### Спосіб 3 — готовий промпт для вашої локальної нейромережі
Якщо у вас на комп’ютері вже працює Claude Code, Codex, Antigravity або інший ШІ-помічник, скопіюйте цей текст повністю й надішліть йому:

```text
Встанови й підготуй до запуску локальний десктопний застосунок AllY · Джинні (v0.1) на цьому ПК Windows із репозиторію https://github.com/AyarZero/ally-dzhinni:
1. Перевір у терміналі наявність `git`, `python` (Python 3) і `node` (потрібна версія Node.js 24+ з успішною перевіркою `node -e "require('node:sqlite')"`). Якщо чогось бракує або версія Node нижча за 24 — повідом мені й допоможи встановити потрібне перед збиранням.
2. Клонуй репозиторій у короткий шлях без кирилиці й пробілів, наприклад `C:\AllY`, і перейди в цю папку.
3. Запусти встановлення: `powershell -NoProfile -ExecutionPolicy Bypass -File .\ustanovka.ps1` і дочекайся збирання `programma\Dzhinni.exe`.
4. Перевір збірку командою `powershell -NoProfile -ExecutionPolicy Bypass -File .\ustanovka.ps1 -Proverka`.
5. Перевір, які CLI-рушії (Claude Code, Codex, Antigravity, DeepSeek Harness, Qoder) або ключі OpenRouter уже доступні в системі, і коротко підкажи мені, що вже готове.
6. Запусти `programma\Dzhinni.exe` (або `.\AllY.exe`) і скажи мені, що можна відкривати вікно AllY та починати роботу.
```

*Примітка: підключені CLI-виконавці працюють із файлами відкритої робочої папки безпосередньо, без запиту на кожне читання чи редагування — тримайте важливі проєкти під Git.*

## Зворотний зв’язок та участь у розвитку проєкту

У правій частині шапки (ліворуч від годинника) розташована кнопка зі **значком жучка — «Зворотний зв’язок»**. Через неї прямо з інтерфейсу можна:

- повідомити про помилку, несправність інтерфейсу або проблему запуску;
- прикріпити до повідомлення до **3 файлів** на підтвердження: текстові журнали `.txt` / `.md` (до `2 МБ`), знімки екрана `.png` / `.jpg` / `.jpeg` / `.webp` / `.gif` (до `10 МБ`) або короткі відео `.mp4` / `.webm` / `.mov` (до `25 МБ`, сумарно до `30 МБ`);
- запропонувати новий модуль, навичку або сценарій використання.

Надсилаються **лише текст форми й вибрані вами файли** — листування, особисті нотатки й ключі залишаються локально. Відповіді розробників надходять назад у листування застосунку. Проєкт відкритий за ліцензією MIT: ви можете створювати власні навички в `.claude/skills/` і брати участь у доопрацюванні ядра.

## Відомі проблеми й обмеження v0.1, над якими ми зараз працюємо

Ми чесно фіксуємо те, що поки обмежене або доопрацьовується саме зараз:

1. **Залежності середовища встановлюються заздалегідь:** для встановлення `v0.1` потрібні вже встановлені `Node.js 24+`, `Python 3` і `Git` — єдиний автономний `.exe`-інсталятор без ручної підготовки програмного забезпечення ще в роботі.
2. **Голосове введення й озвучення приховані в клієнтській збірці v0.1:** кнопки мікрофона й голосу тимчасово прибрано на етапі доопрацювання локального розпізнавання мовлення (`GigaAM`) і його інсталятора.
3. **Щоденник («Чесна розмова») прихований у клієнтській збірці v0.1:** доопрацьовується підтримка всіх рушіїв; вкладка відкриється у найближчому оновленні.
4. **Поступове засинання фонового мосту після закриття вікна:** після закриття вікна локальний сервер мосту може завершувати роботу за тайм-аутом простою (до ~9 хвилин), якщо одразу повторно відкривати інший екземпляр.
5. **Qoder у процесі інтеграції:** майстер підключень визначає локальний CLI Qoder і статус входу, але використання Qoder у ролі провідного виконавця в листуванні поки закрите до наступного релізу.
6. **Поетапне впровадження серверного приймання великих вкладень у відгуках:** якщо під час надсилання знімка екрана або відео сервер відгуків поверне помилку розміру чи відхилить файл до завершення оновлення бекенду, форму можна одразу надіслати текстом без втрати чернетки.
7. **Платформа:** протестовано й зібрано лише під **Windows 10/11**.
