# AllY · جيني (v0.1)

واجهة سطح مكتب محلية لنظام Windows تجمع عدة نماذج ذكاء اصطناعي في نافذة واحدة مع سجل محادثات مشترك، وذاكرة محلية على القرص، وقائمة انتظار للمهام، ومراقبة للحدود.

*يوم ميلاد AllY · جيني — 23 نوفمبر 2026. الترخيص: MIT.*

---

## ما هذا التطبيق وما المشكلة التي يحلها

عند العمل المنتظم مع الذكاء الاصطناعي، تتشتت المهام بسرعة بين تبويبات المتصفح، ونوافذ الطرفية، والمفاتيح المنفصلة. وعندما ينفد حد الخمس ساعات لأحد النماذج، تضطر إلى فتح نموذج آخر وشرح سياق المشروع من جديد.

يعالج **AllY · جيني** أربع مهام عملية:

- **سياق موحد بين النماذج.** يُحفظ سجل المحادثة وقاعدة القواعد الخاصة بك محلياً في ملفات Markdown (`pamyat/`). يمكنك تبديل محرك الذكاء الاصطناعي أو النموذج أو عمق الاستدلال مباشرة من حقل الإدخال، ليستأنف النموذج التالي المهمة من نفس النقطة.
- **شفافية عمل وكلاء CLI.** في الطرفية العادية، يصعب ملاحظة الخطوة الحالية للوكيل في الوقت المناسب والتدخل أثناء التنفيذ. يعرض AllY على اليسار كرة الحالة وشريط الإجراءات الجارية خلف فاصل عمودي سلس قابل لتغيير العرض، بينما تظهر على اليمين المحادثة وقائمة انتظار المهام مع دعم التوضيح الفوري أثناء التنفيذ (`live-steer`)، وتعديل قائمة الانتظار، وتسريع الرسائل المهمة.
- **مراقبة الحدود ونافذة السياق.** تعرض أداة **«الموارد»** النموذج القيادي، ونسبة امتلاء السياق (مع عتبة `350k`)، وحصص الاشتراكات لخمس ساعات وأسبوعية، بينما يجمع تبويب **«المساعدون»** أرصدة الاتصالات الأخرى. تُقرأ المؤشرات محلياً دون أي استدعاءات خلفية مدفوعة.
- **التحكم في البيانات والاتصالات المباشرة.** تبقى المحادثات وملاحظات `pamyat/` ومهارات `.claude/skills/` والإعدادات المحلية `.ally-data/` على جهازك. وتستخدم اشتراكاتك ومفاتيحك الخاصة مباشرة لدى المزودين الذين تختارهم.

## لمن صُمم هذا التطبيق

- **المطورون ومطورو vibe coding** الذين يديرون مشاريعهم عبر Claude Code أو Codex أو Antigravity أو DeepSeek ويرغبون في رؤية خطوات الوكلاء وقائمة الانتظار واستهلاك السياق في نافذة واحدة قابلة للإدارة.
- **الكتّاب ورواد الأعمال والمتخصصون** الذين يحتاجون إلى ذاكرة محلية موحدة لمشاريعهم على حاسوبهم الشخصي.
- **مستخدمو Windows 10/11** الذين يبحثون عن أداة محلية مع إمكانية تخصيص تخطيط الواجهة لاحتياجاتهم، والمشاركة في توجيه الإصدارات القادمة عبر آلية الملاحظات المدمجة.

## ما يعمل فعلياً في الإصدار 0.1

### 1. الاتصالات ووضع «التلقائي»
للبدء، يكفي ربط خيار واحد على الأقل. في وضع **«التلقائي»** يختار النظام المنفذ المتاح تلقائياً:

| الاتصال | آلية العمل | ما يقدمه في v0.1 |
|---|---|---|
| **Claude Code** | CLI رسمي عبر اشتراك Anthropic Pro / Max | المهام المعقدة، البرمجة، النصوص، التخطيط، والضغط التلقائي للسياق |
| **Codex** | CLI رسمي عبر اشتراك ChatGPT Plus / Pro | العمل على المستودعات والتوضيح الفوري أثناء الرد (`live-steer`) |
| **Antigravity** | CLI رسمي من Google AI | التحليلات ذات السياق الكبير (عتبة نافذة `350k`) وتتبع الحصص |
| **DeepSeek Harness** | ملف تعريف محلي دون واجهة `dsh` عبر رصيد DeepSeek | منفذ احتياطي واقتصادي، مع التحقق من الرصيد في تبويب «المساعدون» |
| **مجمع API (OpenRouter)** | أي بوابة متوافقة مع Anthropic عبر Base URL ومفتاح | ربط نماذج خارجية عبر عملية Claude Code CLI المحلية (دون الحاجة لاشتراك Anthropic) |
| **Qoder CLI** | CLI محلي (اكتشاف وتسجيل دخول) | يتعرف عليه معالج الاتصال (بما في ذلك تسجيل الدخول من داخل النافذة)؛ دور النموذج القيادي في المحادثة سيصدر في التحديث القادم |

### 2. مساحة العمل والواجهة
- **شاشة البداية:** على جانب تظهر **«المحادثة»** مع كرة حالة صافية بلا نص وشريط خطوات حي وفاصل سلس، وعلى الجانب الآخر **«الموارد» / «المساعدون»** (أعلى) و**«الحاسوب»** (أسفل) مع قابلية تغيير الارتفاع بحرية.
- **الشريط العلوي (من اليمين إلى اليسار):** الساعة عند الحافة، لوحة **الملاحظات الواسعة (أيقونة الحشرة)**، **الفرشاة** (تحريك الكتل وتغيير حجمها وإعادة الضبط)، **السمات** (**الجرافيت** افتراضياً، مع الفيروزي ومنتصف الليل والداكن والفاتح)، **أيقونة الكتاب** (الدليل وسجل الإصدارات داخل التطبيق) وأيقونة **البرق** (معالج من 3 خطوات مع **«وضع القراءة»** بعرض كامل).
- **التخزين المحلي:** `pamyat/` (ذاكرة Markdown المحلية)، `.claude/skills/` (المهارات المحلية)، `.ally-data/` (المفاتيح وتخطيط النافذة، مستبعدة من Git).

## التثبيت والتشغيل (Windows 10/11)

**قبل التثبيت، تأكد من توفر الأدوات التالية في النظام وفي متغير `PATH`:**
1. **Node.js 24+** (مع دعم الوحدة المدمجة `node:sqlite`)
2. **Python 3**
3. **Git**
4. اتصال بالإنترنت أثناء البناء الأول (`npm ci` وتنزيل Electron)، وتوفر محرك ذكاء اصطناعي واحد على الأقل أو مفتاح متصل.

اختر أياً من طرق التثبيت الثلاث المريحة:

### الطريقة 1 — عبر الأرشيف وملف `.exe` المعتاد
1. نزّل أرشيف ZIP للمستودع وفك ضغطه في مسار قصير خالٍ من الأحرف غير اللاتينية، مثل `C:\AllY`.
2. انقر نقراً مزدوجاً على **`AllY.exe`** — عند التشغيل الأول سيتحقق من وجود `node` 24+ و`python` و`git`، ويثبت الاعتماديات، وينزّل Electron، ويبني الملف التنفيذي **`programma\Dzhinni.exe`**، وينشئ اختصار **`AllY`** على سطح المكتب ثم يفتح النافذة تلقائياً.
  *إذا عرض Windows SmartScreen تحذيراً لملف `.exe` جديد غير موقّع، اختر **معلومات إضافية ← التشغيل على أي حال** (الشيفرة المصدرية للمشغّلات مفتوحة في `docs/launchers/`، أو شغّل `.\ustanovka.ps1` مباشرة).*
3. في المرات التالية، شغّل التطبيق بالنقر المزدوج على **`AllY.exe`**، أو اختصار **`AllY`** على سطح المكتب، أو مباشرة عبر **`programma\Dzhinni.exe`**. ولفتح الدليل وسجل الإصدارات في نافذة تطبيق مستقلة، شغّل **`AllY-Guide.exe`**.
4. عند التشغيل الأول، ستظهر شاشة معالج البداية من 3 خطوات — اربط النموذج المطلوب وأرسل رسالتك الأولى.

### الطريقة 2 — بأوامر الطرفية (PowerShell / cmd)
افتح PowerShell ونفّذ الأوامر التالية بالترتيب:

```powershell
git clone https://github.com/AyarZero/ally-dzhinni.git C:\AllY
cd C:\AllY
.\AllY.exe
```

يمكنك التحقق من جاهزية البناء لاحقاً عبر الأمر:

```powershell
.\AllY.exe -Proverka
```

التشغيل من الطرفية:

```powershell
.\AllY.exe
```

### الطريقة 3 — موجه جاهز لنموذج الذكاء الاصطناعي المحلي لديك
إذا كان لديك Claude Code أو Codex أو Antigravity أو أي مساعد ذكاء اصطناعي يعمل بالفعل على جهازك، فانسخ هذا النص كاملاً وأرسله إليه:

```text
قم بتثبيت وتجهيز تطبيق سطح المكتب المحلي AllY · جيني (v0.1) للتشغيل على جهاز Windows هذا من المستودع https://github.com/AyarZero/ally-dzhinni:
1. تحقق في الطرفية من توفر `git` و`python` (Python 3) و`node` (يلزم الإصدار Node.js 24+ مع نجاح الاختبار `node -e "require('node:sqlite')"`). إذا كان هناك أي نقص أو كان إصدار Node أقدم من 24، فأبلغني وساعدني في التثبيت قبل البناء.
2. استنسخ المستودع في مسار قصير خالٍ من المسافات والأحرف غير اللاتينية، مثل `C:\AllY`، وانتقل إلى هذا المجلد.
3. شغّل التثبيت: `powershell -NoProfile -ExecutionPolicy Bypass -File .\ustanovka.ps1` وانتظر اكتمال بناء `programma\Dzhinni.exe`.
4. تحقق من البناء عبر الأمر `powershell -NoProfile -ExecutionPolicy Bypass -File .\ustanovka.ps1 -Proverka`.
5. افحص محركات CLI (Claude Code، Codex، Antigravity، DeepSeek Harness، Qoder) أو مفاتيح OpenRouter المتوفرة بالفعل في النظام، وأخبرني باختصار بما هو جاهز.
6. شغّل `programma\Dzhinni.exe` (أو `.\AllY.exe`) وأبلغني بأنه يمكنني فتح نافذة AllY وبدء العمل.
```

*ملاحظة: تتعامل أدوات CLI المتصلة مع ملفات مجلد العمل المفتوح مباشرة دون طلب إذن لكل قراءة أو تعديل — احرص على إبقاء مشاريعك المهمة تحت إدارة Git.*

## الملاحظات والمساهمة في تطوير المشروع

في الجهة اليمنى من الشريط العلوي (على يسار الساعة) يوجد زر **أيقونة الحشرة — «الملاحظات»**. من خلاله يمكنك مباشرة من داخل الواجهة:

- الإبلاغ عن خطأ برمجي، أو خلل في الواجهة، أو مشكلة في التشغيل؛
- إرفاق حتى **3 ملفات** توضيحية مع الرسالة: سجلات نصية `.txt` / `.md` (حتى `2 MB`)، أو لقطات شاشة `.png` / `.jpg` / `.jpeg` / `.webp` / `.gif` (حتى `10 MB`)، أو مقاطع فيديو قصيرة `.mp4` / `.webm` / `.mov` (حتى `25 MB`، وبإجمالي لا يتجاوز `30 MB`)؛
- اقتراح وحدة جديدة، أو مهارة، أو سيناريو استخدام.

يتم إرسال **نص النموذج والملفات التي تختارها فقط** — بينما تبقى المحادثات والملاحظات الشخصية والمفاتيح محلياً. وتصل ردود المطورين مباشرة إلى محادثة التطبيق. المشروع مفتوح المصدر تحت رخصة MIT: يمكنك إنشاء مهاراتك الخاصة في `.claude/skills/` والمشاركة في تطوير النواة.

## المشاكل والقيود المعروفة في v0.1 التي نعمل عليها حالياً

نوثق بشفافية الجوانب التي لا تزال مقيدة أو قيد الاستكمال في الوقت الحالي:

1. **تُثبّت اعتماديات البيئة مسبقاً:** يتطلب تثبيت `v0.1` وجود `Node.js 24+` و`Python 3` و`Git` مثبتة مسبقاً — ولا يزال المثبت المستقل الموحد بصيغة `.exe` دون إعداد يدوي للبرامج قيد التطوير.
2. **إخفاء الإدخال الصوتي والقراءة الصوتية في نسخة العميل v0.1:** أُزيلت أزرار المיקروفون والصوت مؤقتاً أثناء مرحلة تحسين التعرف المحلي على الكلام (`GigaAM`) ومثبّته.
3. **المفكرة («حديث صريح») مخفية في نسخة العميل v0.1:** يجري إكمال دعم جميع المحركات، وسيُفتح التبويب في التحديث القادم.
4. **الإغلاق المتدرج للجسر الخلفي بعد إغلاق النافذة:** عند إغلاق النافذة، قد ينتهي عمل خادم الجسر المحلي بعد مهلة الخمول (تصل إلى ~9 دقائق) إذا أعدت فتح نسخة أخرى فوراً.
5. **Qoder قيد التكامل:** يتعرف معالج الاتصالات على Qoder CLI المحلي وحالة تسجيل الدخول، لكن استخدام Qoder كنموذج قيادي في المحادثة لا يزال مغلقاً حتى الإصدار القادم.
6. **موجة تحديث الخادم لاستقبال المرفقات الكبيرة في الملاحظات:** إذا أعاد خادم الملاحظات خطأً حول الحجم أو رفض الملف عند إرسال لقطة شاشة أو فيديو قبل اكتمال تحديث الخادم الخلفي، يمكنك إرسال النموذج نصياً فوراً دون فقدان المسودة.
7. **المنصة:** تم الاختبار والبناء لنظام **Windows 10/11** فقط.
